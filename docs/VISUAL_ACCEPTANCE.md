## 2. E2E Baseline Reconciliation

- **`pnpm e2e`**: Runs Cypress end-to-end testing against all 9 test specs (`j1` through `j8` plus `smoke.cy.ts`).
  - Total tests: **20 tests** across 9 specs.
  - Result: **20 passing, 0 failing, exit code 0**.
- **`pnpm e2e:a11y`**: Runs Cypress end-to-end testing specifically targeted to accessibility checkpoints across 5 designated specs (`j1`, `j2`, `j4`, `j6`, `j8`).
  - Total tests: **14 tests** across 5 specs.
  - Result: **14 passing, 0 failing, exit code 0, 0 Axe violations**.
- **Reconciliation Note**: Phase 0 reported 14 tests because `pnpm e2e && pnpm e2e:a11y` were chained together, and the final output summary was from the 14-test targeted accessibility subset. The full journey suite executes 20 tests. Both suites pass completely.

## 3. Visual Acceptance Protocol for Subsequent Phases

1. Every phase must reference its corresponding requirement IDs from this map.
2. Automated tests in `presentation.test.tsx` and existing test suites must pass before and after each phase.
3. No visual styling change may weaken existing semantics, accessible labels, test IDs, or error handling.
