# safe-money-ui

_Money-correct, failure-tolerant UI primitives for React and TypeScript, with a chaos-mode demo._

[![CI](https://github.com/Satjeet2005/safe-money-ui/actions/workflows/ci.yml/badge.svg)](https://github.com/Satjeet2005/safe-money-ui/actions/workflows/ci.yml)

A payment UI can be built so that malformed input, duplicate clicks, slow or lost responses, stale data and bad payloads never produce a false success or a double submission, and every one of those claims is backed by a test a reviewer can run in under five minutes.

- Live demo: `<DEMO_URL>`
- Walkthrough video: `<VIDEO_URL>`

## Quick start

```bash
corepack enable && pnpm install --frozen-lockfile
pnpm dev
pnpm verify
```
